# Döbel Leipzig · Worldflight Score

## Representation gate

- Target: one continuous browser-native realtime building-services world.
- Importance: primary medium across the full homepage.
- Candidates: layered photographic act stack; pre-rendered scrub video; procedural WebGL plus DOM copy and photographic fallback.
- Selected: procedural WebGL plus DOM and repository-image fallback. It supports live camera, material, object, light and particle interpolation without Unreal, external 3D files or video decoder risk.
- Technical bounds: static hosting, mobile pixel-ratio cap, no shadows or post-processing, bounded geometry, paused hidden tabs, reduced-motion and WebGL failure fallbacks.
- Proof: real renderer startup, full 0–100% state sweep, build, semantic QA, overflow checks and runtime error inspection.
- Stop: blocking renderer errors, unreadable copy, inaccessible primary actions, or motion that cannot degrade.

## Grammar

Worldflight. This is the explicit owner choice: one unbroken world with no document-flow content except the spacer.

## Fingerprint gate

Compared with the shipped Split Stage preview, the new plan changes all six dimensions:

1. Grammar: Split Stage → Worldflight.
2. Navigation: sparse perimeter chrome → thermodynamic route rail.
3. Hero: paired photographic poles → realtime system assembly approach.
4. Shape: seven mixed acts → eight continuous camera legs across one global track.
5. Close: paper aperture collapse → system lock and operational contact frame.
6. Signature: Thermal Exchange Seam → Self-Rewiring Building Circuit.

## Signature move

## Responsive contract

- Desktop: full realtime 3D, displaced callouts, fine-pointer camera response.
- Tablet: full scene with lower DPR and reduced particle count.
- Phone: camera reframed vertically, simplified secondary geometry, large fixed copy zone and persistent call action.
- Reduced motion: no autonomous orbit or pointer motion; timeline still resolves through static keyed states.
- No WebGL: repository photography cross-dissolves under the same copy windows and actions.
